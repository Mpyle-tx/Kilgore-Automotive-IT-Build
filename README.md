# Small-Business IT Infrastructure Build

Network and server build for a local automotive service business. Independent contractor project, ongoing.

## What I built

- Virtualization host: Dell PowerEdge R630 running Proxmox VE, hosting Windows VMs, a Linux file server, and a local AI inference container
- Network: MikroTik RouterOS with five VLANs (servers, office, phones, payment/PCI, management) for security and traffic isolation
- Services: Pi-hole for network-wide DNS filtering and Nginx Proxy Manager for reverse proxy and SSL
- Resilience: remote access, automated backups, and UPS-monitored power

## My role

Designed, deployed, and maintain the environment, from hardware selection through day-to-day administration.

## Tools

Proxmox VE, MikroTik RouterOS, VLANs, Pi-hole, Nginx Proxy Manager, Windows Server, Linux
